# Skill 行为实测

日期：2026-10-19。除了真实 CLI 集成测试，还做了两次独立代理测试，检查指令能否帮助执行任务。测试资料与网页内容均视作数据，不授予额外操作权限。

## 未加载 Skill 的基线

给定 39 帧 GIF：前 38 帧各 40 ms，末帧 450 ms；动画面板时长 1.6 s，动画事件时间 0.86 s；仅本地、纯音效、无环境底声。

代理正确计算播放时长为 1.970 s，但直接沿用了 0.86 s 的动画事件时间，未将其映射到实际 GIF 帧起点。这个观察只说明该次执行遗漏了时钟转换，不能推断所有未加载 Skill 的执行都会失败。

## 加载 Skill 后的独立执行

另一代理读取 Skill、原始视频和脚本，未读取或复制首例的计划与输出音频，也未修改 Skill。它实际执行 `inspect`、独立编写计划、`render --stems`、`verify`，另抽取全部 69 帧核对动作，并使用独立脚本检查媒体。

- 视频：960 × 720，30 fps，2.300 s。
- 首次清楚脱手：零基第 15 帧，0.500 s。
- 首次落地碎散：零基第 41 帧，1.366667 s。
- 自主安排了蓄力轻擦、出手破风、下坠、软团落地与颗粒收尾等六个声层。
- WAV：48 kHz / PCM 24-bit / stereo，每声道 110400 帧，2.300 s。
- WAV 峰值 −3.000 dBFS；4 倍过采样峰值 −2.989 dBFS；1.766667 s 后严格静音。
- 同步 MP4：H.264 / AAC，音画各 2.300 s，完整解码通过。
- AAC 与 WAV 波形相关检查：在 ±50 ms 搜索内偏移为 0 个采样。

独立 WAV SHA-256：`0f14dd68cd4662e325128d7711b9d00d317dbc352f6a539f5e3e997b3d8acac6`。此文件属于独立执行记录，并非首例交付 WAV；首例输出及其校验值见 [首例报告](../examples/01-projectile-throw/test-report.md)。

对相同 GIF 变体，代理得出：总时长 1.970 s、94560 采样帧；若 39 张图像均匀采样动画 0..1.6 s，则事件首次出现于 `ceil(0.86 / 1.6 × 38) = 21` 号图像，对应媒体起点 **0.840 s**。30 fps MP4 可补末帧到 2.000 s，WAV 不拉伸。

## 审查与回归

独立代码审查发现 GIF 的 10 ms 延迟被 FFmpeg 默认最小延迟改写、奇数尺寸不能直接编码 yuv420p，以及报告/分轨覆盖保护不完整。先用真实媒体测试复现，再修复并重跑；覆盖保护还扩展到批量索引和压缩包。测试文件为 [test_workflow.py](test_workflow.py)，其中极短帧延迟测试会检查预览的最终图像内容，而非只检查文件时长。

全部生成及检查在本地进行。没有调用远程模型或上传生成服务，也未使用播放工具试听；格式、时序和静音校验不等于审美或听感验收。
